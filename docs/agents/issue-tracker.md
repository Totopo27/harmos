# Issue Tracker

Issues for this project are tracked using **GitHub Issues** in the official repository:
`Totopo27/harmos`

## Usage for Skills

- Skills like `to-spec`, `to-tickets`, and `triage` read and write issues via the GitHub CLI (`gh`).
- New issues are created with:
  ```bash
  gh issue create --title "<title>" --body "<body>"
  ```
- To list open issues:
  ```bash
  gh issue list
  ```
- To view an issue:
  ```bash
  gh issue view <issue-number>
  ```
